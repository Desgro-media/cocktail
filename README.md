# Cocktail Custom Prints

Custom printed T-shirts, shirts, hoodies and caps — Trivandrum, shipping all over India.
Instagram: https://www.instagram.com/cocktail_custom_/

React 19 + Vite + Tailwind. Run with `npm install && npm run dev`.

## Editing content
- **Products, prices, sizes, FAQs:** `src/data/products.js` (prices are placeholders — update them).
- **Product photos:** put files in `public/products/` named `<slug>-1.jpg`, `<slug>-2.jpg`
  (e.g. `kids-ayyappa-shirt-1.jpg`). Until a photo exists a branded placeholder is shown.
- **Instagram reels on the homepage:** `src/components/InstagramReels.jsx` (list of reel IDs).
- **WhatsApp / Instagram links, brand text:** `BRAND` in `src/data/products.js`.
